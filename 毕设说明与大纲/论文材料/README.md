# 论文材料（第一版）

本文件夹存放毕业论文（设计）各阶段文档的**初稿**，便于先完成第一版论文再继续毕设开发。

## 当前文件

| 文档       | 文件           | 说明 |
|------------|----------------|------|
| 任务书     | [任务书.md](./任务书.md)     | 课题名称、背景与意义、主要任务与目标、工作内容与要求、进度安排、参考文献 |
| 开题报告   | [开题报告.md](./开题报告.md) | 选题背景与意义、国内外研究现状、研究内容与目标、研究方法与技术路线、进度安排、参考文献 |

## 使用说明

1. **格式**：学院若提供 Word 模板或固定版式，请将本 Markdown 内容复制到模板中，并调整标题层级、页眉页脚、参考文献格式等。
2. **参考文献**：示例中部分文献的卷期、页码写为 `x`，需根据实际查阅的文献补全；并按学院要求统一为国标或学校规定格式。
3. **进度安排**：表中周次为示例，须与《河北师范大学汇华学院关于做好 2026 届毕业生毕业论文（设计）工作的通知》中的时间节点一致。
4. **指导教师意见**：任务书与开题报告末尾的“指导教师意见”由教师填写，提交前保留空白或按学院要求处理。
