# 软件测试平台后端接口文档

本目录用于**统一整理后端所有 HTTP 接口**，并按业务模块分类。

- **文档位置**：`backend/docs/api`
- **接口风格**：RESTful JSON
- **统一前缀**：`/api`（见各模块说明）
- **认证方式**：基于 JWT 的 Bearer Token（除登录、注册、健康检查外多数接口都需要）

## 文档结构

- `api/auth-api.md`：认证 & 当前用户相关接口（登录、注册、获取当前用户信息）
- `api/system-api.md`：系统基础接口（健康检查等）
- `api/ui-test-api.md`：UI 自动化测试相关接口（测试用例、执行、执行实例）
- `api/api-test-api.md`：API 接口测试相关接口（接口集合、环境变量、发送请求）

## 接口文档约定

每个接口会说明：

- **接口名称**：该接口的业务含义
- **请求方式 & 路径**：如 `POST /api/auth/login`
- **是否需要认证**：是否必须携带 `Authorization: Bearer <token>`
- **请求参数**
  - Query / Path / Body 参数列表
  - 字段类型、是否必填、含义
- **响应数据**
  - 返回 JSON 结构说明
- **可能的错误码**：常见 HTTP 状态码和含义（如 400、401、404 等）

后续如新增后端接口，建议：

1. 在对应模块的 `*.md` 文件中补充接口说明；
2. 或新增一个新的 `*-api.md` 文件，并在本文件的「文档结构」中登记。
