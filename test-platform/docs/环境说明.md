# 环境说明（阶段 0）

## 必需环境

### 1. 后端

- **JDK 17+**（本后端使用 Java 17 编译，必须用 JDK 17 或更高）  
  - 检查：`java -version`，应显示 17 或以上。  
  - **若出现「不支持发行版本 17」**：说明 Maven 用的不是 JDK 17（例如用的是 JDK 8/11）。请：  
    1. 在命令行执行 `mvn -v`，看第一行 “Java version” 是多少。  
    2. 将 **JAVA_HOME** 指向 JDK 17 的安装目录（例如 `C:\Program Files\Java\jdk-17`）。  
    3. 确保 PATH 里 `%JAVA_HOME%\bin` 在其它 Java 前面，或先设 JAVA_HOME 再运行 Maven。  
  - 在 IDEA 中：File → Project Structure → Project → SDK 选 17；Settings → Build → Maven → Runner → JRE 选 17。
- **Maven 3.6+**（或使用 IDE 自带 Maven）  
  - 检查：`mvn -v`，其中的 “Java version” 必须为 17+。
- **MySQL 8.x**（推荐）或 5.7+  
  - 启动 MySQL 服务后，创建数据库：  
    ```sql
    CREATE DATABASE test_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    ```
  - 修改 `backend/src/main/resources/application.yml` 中的 `spring.datasource.username`、`spring.datasource.password` 为你的 MySQL 账号密码。

### 2. 前端

- **Node.js 18+**  
  - 检查：`node -v`
- **npm**（随 Node 安装）  
  - 检查：`npm -v`

---

## 首次运行

### 后端

```bash
cd test-platform/backend
mvn spring-boot:run
```

或使用 IDE 运行 `com.testplatform.TestPlatformApplication`。

- 成功：控制台出现 “Started TestPlatformApplication”
- 验证：浏览器访问 `http://localhost:8080/api/health`，应返回 `{"status":"ok","service":"software-test-platform"}`

### 前端

```bash
cd test-platform/frontend
npm install
npm run dev
```

- 成功：终端提示 `Local: http://localhost:5173/`
- 验证：浏览器打开 `http://localhost:5173`，应看到登录占位页；点击「进入系统」进入侧边栏布局，可切换「接口测试」「UI 测试」；点击入口按钮可进入占位子页面。前端通过 Vite 代理访问后端 `/api`，无需单独配置 CORS。

## 暂无 MySQL 时

若暂时未安装 MySQL，可先改用 H2 内存数据库跑通后端：

1. 在 `backend/pom.xml` 的 `<dependencies>` 中增加：
   ```xml
   <dependency>
       <groupId>com.h2database</groupId>
       <artifactId>h2</artifactId>
       <scope>runtime</scope>
   </dependency>
   ```
2. 在 `application.yml` 中注释掉 MySQL 的 `datasource` 与 `jpa.dialect`，改为：
   ```yaml
   spring:
     datasource:
       url: jdbc:h2:mem:test_platform
       username: sa
       password:
       driver-class-name: org.h2.Driver
     jpa:
       database-platform: org.hibernate.dialect.H2Dialect
   ```
3. 重新启动后端即可（无需建库）。阶段 1 做用户表时再切回 MySQL 也可。
